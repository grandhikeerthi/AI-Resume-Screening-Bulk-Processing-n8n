AI Resume Screening – Bulk Processing using n8n
📌 Project Description
AI Resume Screening – Bulk Processing is an AI-powered recruitment automation project built using n8n. It helps recruiters and HR teams automatically process and analyze multiple resumes against a given Job Description (JD).
The workflow extracts important information from resumes, identifies relevant technical skills, compares candidate skills with the job requirements, and generates a structured analysis. It can process resumes in bulk, reducing the amount of manual effort required for initial resume screening.

🎯 Objectives
Automate the initial resume screening process.
Process multiple resumes efficiently.
Compare resumes with a specific Job Description.
Identify matching and missing skills.
Generate structured candidate analysis reports.
Categorize candidates based on the screening criteria.
Maintain application screening results in an organized manner.

🛠️ Technologies Used
n8n – Workflow automation
AI/LLM – Resume analysis and skill matching
Google Drive – Resume storage
Google Sheets – Candidate/application tracking
Job Description – Used as the screening criteria

🔄 Workflow
Resume Upload → Resume Extraction → AI Analysis → Job Description Matching → Screening Result → Google Sheets → Report/Notification

📊 Information Analyzed
The system can analyze:
Candidate name
Email
Phone number
Technical skills
Education
Experience
Projects
Skills matching the Job Description
Missing/recommended skills
Estimated matching percentage

🚀 Key Feature
the main feature of this project is bulk resume processing, where multiple resumes can be handled through an automated n8n workflow instead of manually reviewing each resume one by one.

💡 Benefits
Saves time during initial resume screening.
Reduces repetitive manual work.
Provides consistent analysis.
Organizes candidate information.
Helps recruiters handle a large number of applications more efficiently.

👩‍💻 Project Type
AI + Automation + Recruitment Technology
This project is designed as an automated initial screening and application tracking system. Final hiring decisions should still be made by qualified human recruiters.
